Семейный бюджет — PWA для совместного учёта расходов: несколько пользователей в одной семье записывают траты, видят общую статистику и план по категориям.

Стек: Node.js + Express, ванильный JS без фреймворков, Socket.IO для real-time синхронизации, Chart.js для графиков, JWT-аутентификация, JSON-файл как хранилище, Service Worker для PWA.

Сейчас в фокусе: premium Glass UI — glassmorphism-карточки, градиентный фон, шрифт Onest, анимации при добавлении расходов. Вкладки «Месяц» и «План» объединены: категории показывают прогресс-бар к лимиту и остаток/перерасход, в режиме сравнения — % от дохода по каждому пользователю.

Недавно докрутили: AI-разбор расходов из свободного текста (Claude API), единый интерактивный график (доходы + расходы + баланс, zoom/pan), мульти-семейная изоляция данных.

Специфика: zero frontend deps (всё через CDN), хранение в JSON без БД, AI-фичи опциональны.

# Публикация в Google Play — чек-лист

Всё, что нужно, чтобы залить приложение в закрытый тест и потом в продакшн.
Пакет приложения: **`com.familybudget.app`** (менять нельзя после первой загрузки).

---

## 1. Секреты в GitHub (одноразово)

Repo → **Settings → Secrets and variables → Actions → New repository secret**.
Добавь 4 секрета (значения я дам в чате — в файл их не кладём):

| Имя секрета | Что это |
|---|---|
| `RELEASE_KEYSTORE_BASE64` | ключ подписи (upload key), base64 |
| `KEYSTORE_ALIAS` | `familybudget-upload` |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_PASSWORD` | пароль ключа (тот же) |

> 🔐 Это **upload-ключ**. Даже если потеряешь — при включённом Play App Signing Google
> поможет сбросить его. Но лучше сохранить base64 и пароль в надёжном месте.

## 2. Собрать AAB для Play

GitHub → **Actions → «Android APK Build» → Run workflow** → в поле `build_type` выбрать
**`store`** → Run. Через ~13 минут в артефактах появится **`family-budget-store-N`** —
внутри `app-release.aab`. Это и есть файл для Play (не APK).

## 3. Play Console — создать релиз закрытого теста

1. **Testing → Closed testing → Create track** (или используй трек «Alpha»).
2. **Testers**: создай список из **≥ 12 email** (Google-аккаунты тестировщиков),
   привяжи к треку. Скопируй **opt-in ссылку** и разошли — каждый должен нажать
   «Стать тестировщиком».
3. **Create release** → загрузи `app-release.aab`.
4. При первой загрузке Google предложит включить **Play App Signing** — соглашайся
   (это стандартно; наш ключ становится upload-ключом).
5. Заполни «Release notes» (что нового) → Review → **Start rollout to Closed testing**.

⏱️ **Правило 14 дней / 12 тестировщиков**: трек должен идти непрерывно ≥ 14 дней с
минимум 12 активными тестировщиками, прежде чем откроется заявка на продакшн.

# 💰 Семейный бюджет

Приложение для совместного учёта семейных расходов: несколько человек в одной семье записывают траты и видят общую картину в реальном времени.

Три клиента к одному серверу:

| Клиент | Где | Особенности |
|---|---|---|
| 🌐 **Веб-PWA** | `public/` | Работает на любой платформе (в т.ч. iOS), ставится на главный экран |
| 🤖 **Android-приложение** | `android/` | React Native + Expo; офлайн-режим и локальный ключ шифрования |
| 💬 Telegram-бот | `src/index.js` | Отключён (наследие первой версии) |

## Возможности

**Учёт**
- Лента расходов по дням: фильтр «Все / Я / Партнёр», группировка по участникам, свайпы и календарь для навигации
- Ввод через форму с подсказкой категории, свободным текстом («вчера продукты 2300, такси 450» — разберёт ИИ) или фото чека
- Категории: 12 базовых + свои на семью (с любым эмодзи); при удалении своей категории расходы переезжают в «Прочее»
- Офлайн-режим в приложении: расход сохраняется на телефоне с меткой ⏳ и уходит на сервер при появлении сети

**Аналитика** (каждый блок можно включить/выключить в «Конструкторе аналитики»)
- Месяц: итого и остаток от плана, баблометр-спидометр (факт/план по дням), календарь «Расходы по дням», «Скорость трат», категории с прогрессом лимитов, сравнение с прошлым месяцем, drill-down по категории и дню
- График: дневные расходы по участникам, баланс семьи, кэшфлоу (дебетовая/кредитная/сбережения, поступления по дням)
- Цели: накопления с прогрессом, лимиты по категориям, расчёт сбережений
- 🤖 ИИ-анализ месяца и PDF-отчёт (премиум)

**Семья и приватность**
- Регистрация через Google (веб и приложение), привязка Google к старому аккаунту со слиянием истории
- Приглашение в семью ссылкой или кодом
- Пуш-уведомления о расходах партнёра (отключаемые)
- 🔐 Шифрованные бэкапы: снапшот семьи шифруется AES-256-GCM **на устройстве**, сервер хранит нечитаемый блоб; восстановление — только с ключом-фразой
- Локальный ИИ-классификатор категорий в приложении: обучается на устройстве, данные не покидают телефон; общий краудсловарь пополняется только словами, встречающимися у ≥3 семей (k-анонимность)
- E2E-синхронизация (zero-knowledge) — в разработке: сервер будет хранить только шифротекст

**Оформление**
- Светлая / тёмная / авто-тема, единый фиолетовый дизайн веба и приложения

## Стек

- **Сервер**: Node.js + Express, Socket.IO (real-time), JWT, JSON-файл как хранилище (изоляция семей), OpenRouter для ИИ-фич
- **Веб**: ванильный JS без сборки, Chart.js, Service Worker (PWA), Google Identity Services
- **Android**: React Native 0.74 + Expo SDK 51, SQLite (классификатор и офлайн-очередь), react-native-svg, @noble/ciphers

## Запуск сервера

```bash
npm install
cp .env.example .env   # заполнить переменные
DATA_FILE=./data/expenses.json node src/server.js
```

Переменные окружения:

| Переменная | Назначение |
|---|---|
| `PORT` | Порт (по умолчанию 3000) |
| `DATA_FILE` | Путь к файлу данных (на Amvera — `/data/expenses.json`) |
| `JWT_SECRET` | Секрет токенов |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | Google OAuth (+ добавить redirect URI `https://домен/auth/google/mobile/callback`) |
| `OPENROUTER_API_KEY` | ИИ-фичи (опционально) |

⚠️ `npm start` запускает отключённого телеграм-бота — веб-сервер это `src/server.js`.

## Деплой

- **Amvera**: конфиг `amvera.yml` в корне, постоянное хранилище `/data`. Автодеплой по пушу в ветку **`deploy`**
- **Docker**: `docker build -t budget . && docker run -p 3000:3000 -v budget-data:/data budget`

## Сборка Android

APK собирается в GitHub Actions при пуше в ветку **`android/react-native`** (артефакт `family-budget-standalone-N`, живёт 30 дней). Локальная разработка: `cd android && npm install --legacy-peer-deps && npx tsc --noEmit`.

## Ветки

Политика конфиденциальности

Приложение «Семейный бюджет» · обновлено 19 июля 2026 г.

Настоящая политика описывает, какие данные обрабатывает приложение «Семейный бюджет» (далее — «Приложение») и как они используются. Пользуясь Приложением, вы соглашаетесь с условиями этой политики.

1. Какие данные мы обрабатываем

  • Данные аккаунта: имя и адрес электронной почты (при входе через Google) или логин (при входе по паролю). Пароли хранятся только в виде хеша.
  • Финансовые записи: суммы расходов, категории, описания и даты, которые вы вносите вручную или через распознавание. Эти данные видны участникам вашей семьи в Приложении.
  • Фото чеков: при использовании функции сканирования чека изображение передаётся сервису распознавания для извлечения суммы и категории. Изображение обрабатывается для распознавания и не публикуется.
  • Токен push-уведомлений: технический идентификатор устройства для отправки уведомлений о расходах партнёра. Не содержит персональных данных.

Приложение не собирает геолокацию, контакты, рекламные идентификаторы и не передаёт данные рекламным сетям.

2. Как используются данные

  • для ведения совместного семейного бюджета и синхронизации между участниками семьи;
  • для отправки уведомлений о новых расходах (можно отключить в настройках);
  • для распознавания текста чеков и голосового/текстового ввода расходов;
  • для аутентификации и защиты доступа к вашим данным.

3. Сквозное шифрование (по вашему выбору)

Приложение поддерживает режим сквозного шифрования (E2E). Если вы его включите, финансовые записи шифруются на устройстве, и сервер хранит только зашифрованные данные — прочитать их без вашего ключа невозможно, в том числе для разработчика. Ключ хранится только на ваших устройствах; при его потере восстановить данные нельзя.

4. Передача третьим лицам

Мы не продаём ваши данные. Ограниченные данные обрабатываются поставщиками, необходимыми для работы Приложения:

  • Google — вход через аккаунт Google и доставка push-уведомлений;
  • Поставщик ИИ-распознавания — получает текст/изображение чека для извлечения расхода в момент распознавания;
  • Хостинг-провайдер — размещение сервера и хранение данных.

5. Хранение и удаление

Данные хранятся, пока вы пользуетесь Приложением. Вы можете запросить удаление аккаунта и всех связанных данных, написав на контактный адрес ниже — данные будут удалены с сервера.

6. Безопасность

Соединение с сервером защищено по HTTPS. Пароли хранятся в виде хеша, зашифрованные резервные копии и E2E-данные сервер прочитать не может.

7. Дети

Приложение не предназначено для детей младше 13 лет и не собирает данные о них осознанно.

8. Изменения

Мы можем обновлять эту политику. Дата последнего обновления указана вверху страницы.
